📚 Book Store Analysis (SQL)

📌 Overview
This project analyzes a Book Store dataset using SQL to derive insights related to sales, customers, and books.
It showcases practical SQL skills through real business-style questions and verified query outputs.


🛠️ Tech Stack
Database: PostgreSQL
Language: SQL
Tool: pgAdmin
Data Files: orders.csv, books.csv, customers.csv


📂 Project Structure
Book-Store-Analysis/
├── Book_Store_Analysis.sql     # SQL queries
├── Book_Store_Analysis.pdf     # Questions with output screenshots
├── datasets/
│   ├── orders.csv
│   ├── books.csv
│   └── customers.csv
└── README.md


🔍 Analysis Covered
Sales and revenue analysis
Customer purchase behavior
Best-selling books
Order-based insights
🧠 SQL Concepts Used
JOIN, GROUP BY, WHERE, ORDER BY, SUM, COUNT, subqueries
📄 Project PDF
The PDF file contains:
SQL questions
Corresponding queries
Output screenshots from pgAdmin
This ensures end-to-end proof of analysis.


🚀 How to Use
Import CSV files into PostgreSQL
Run queries from Book_Store_Analysis.sql
Refer to the PDF for questions and outputs
